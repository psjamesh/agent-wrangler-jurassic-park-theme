# Agent Wrangler Jurassic Park theme

An [Agent Wrangler](https://github.com/PortSwigger/agent-wrangler) extension that adds the
Jurassic Park theme: warm amber and jungle-green colours over a park-gate wallpaper.

## Install

In Agent Wrangler, open **Settings › Extensions › + Add extension** and paste:

```
https://github.com/psjamesh/agent-wrangler-jurassic-park-theme
```

Then choose **Jurassic Park** in **Settings › Appearance**. Requires Agent Wrangler host API 1.43.0
or later.

The theme's id is `jurassic-park`, so a browser that had it selected before it moved out of Agent
Wrangler keeps that choice and shows it again once this extension is installed.
